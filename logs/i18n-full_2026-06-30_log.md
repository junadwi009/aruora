# i18n-full — 2026-06-30

Owner report: "bagian Tips saat UI ganti Indonesia tidak berubah… pastikan semua
perintah berubah jadi Indonesia kecuali soal dan test." → full Indonesian coverage
of the interface **and** learner-facing guidance, keeping exam material English.

Owner-chosen content boundary: **Tips + feedback + lesson** localize; only exam
material (reading passages, listening transcripts, questions/options, writing
prompts, roleplay partner reply, vocab target words, pronunciation target
sentence) stays English.

## Why Tips looked "still English"
The prior i18n pass covered only nav/welcome/auth/home/settings chrome. Tips shows
mostly its *content* (advice bullets), which is a **static fixture** — never
localized. And every practice screen's chrome was still hardcoded English.

## What changed

### Backend — learner-facing prose localizes (`a57c867`)
- `X-Lang` request header → `routes/_deps._lang()` ("id"/"en").
- `services/prompts.lang_note(lang)`: returns an Indonesian instruction (empty for
  en) telling the model to write **prose** (feedback, summary, notes, explanations,
  instructions, goals, tips) in Bahasa Indonesia while **keeping English** every
  model answer, rewrite, example, vocab item, and quoted/corrected learner text;
  JSON keys/enums stay English. Injected via a new `{langNote}` placeholder in the
  **writing / speaking / lesson / pronounce-feedback** prompts only.
- `services/llm.LlmGateway.generate/score` take `lang=` and always set
  `fmt_kw["langNote"]` (so templates with the placeholder never KeyError).
- Routes pass `lang=_lang()`: writing.evaluate, speaking.evaluate (NOT roleplay —
  its reply is English conversation practice), lesson.generate, pronounce.feedback.
- **Tips**: `fixtures/tips_id.json` (Indonesian) served when `X-Lang=id`; English
  `tips.json` otherwise. Deterministic, no API cost.

### Frontend — all chrome + auto language header (`dbaf121`)
- `lib/api/client.ts`: every request (incl. multipart upload) sends
  `X-Lang: <localStorage ielts.lang>` — no React dependency.
- Wrapped hardcoded UI strings with `t()` across ~24 components: Tips, Vocab,
  Pronounce, QuizRunner (Reading/Listening share it), Writing, Speaking, Roleplay,
  Recorder, MockTest, Progress, Session, all Placement/*, Program, Milestones,
  menu (Sidebar/BottomTabs), Onboarding, Timer, QuizNavigator. (Reading.tsx/
  Listening.tsx are thin wrappers — nothing to translate.)
- `lib/i18n.tsx`: EN and ID dictionaries grew from 112 → **365 keys** each
  (~253 new). EN values are byte-identical to the previous literals so the unit
  suite (English-fallback when rendered without the provider) stays green. Added
  the missing Indonesian keys for the admin panel too.
- Convention kept: exam content, AI model answers, examples, corrections, and IELTS
  technical terms (True/False/Not Given, Task Achievement, …) stay English.

## How this was built
6 parallel subagents translated disjoint component groups (each wrote a JSON key
map to scratch; no agent edited `i18n.tsx`). A merge script spliced all keys into
the EN/ID dictionaries centrally, so there were no concurrent-edit conflicts.

## Verify
- api: `pytest -q` → **142 passed** (new `test_i18n_backend.py`: lang_note en/id,
  placeholders present in the right prompts + absent from roleplay/reading, Tips
  localizes by X-Lang, gateway accepts `lang=`).
- web: `tsc --noEmit` clean; `vitest run` → **55 passed**; missing-`t()`-key scan
  clean (only dynamic `t("nav."+skill)` false positives).
- Live (docker compose up --build, LLM_MODE=live): `GET /api/tips/reading` →
  "Reading strategy"; with `X-Lang: id` → "Strategi Reading" + Indonesian bullets.
  In Chrome with language = Indonesia: Welcome, Dashboard/sidebar, and the **Tips
  page** (headers + "STRATEGI READING" + all bullets) render Indonesian; IELTS
  terms stay English.

## Caveats
- `t()` has no interpolation, so two strings became generic: `Loading {skill} set…`
  → "Loading set…" / "Memuat set…", and Timer's `${n} seconds remaining` aria-label
  → static. Cosmetic only.
- Localized feedback/lesson prose depends on the live model honoring `langNote`;
  in stub/offline mode fixtures stay English (fine for tests).
- A few deep long-tail strings may remain — extend via the same dictionary.
