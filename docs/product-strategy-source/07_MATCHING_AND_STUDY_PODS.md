# 07 — Matching & Study Pods

## Principle

Similar current band alone is insufficient.

Matching should consider:

- current ability
- target
- weak skill
- timeline
- goal
- availability
- intensity

---

# Initial Heuristic

Use this only as a starting hypothesis:

| Factor | Weight |
|---|---:|
| Current level proximity | 25% |
| Weak-skill overlap | 20% |
| Target-band proximity | 15% |
| Exam/deadline proximity | 15% |
| Goal similarity | 10% |
| Availability overlap | 10% |
| Study intensity | 5% |

Total = 100%.

### HYPOTHESIS

These weights are not evidence-based.

Update them using observed:
- match acceptance
- session completion
- repeat interaction
- no-show
- improvement
- peer rating

---

# Start with Pods, Not 1:1

Early network liquidity will be low.

Recommended:

> **4–8 learners per Study Pod**

Advantages:
- higher chance someone is available
- lower single-person dependency
- group accountability
- easier manual operations

---

# Manual Before Automated

### Phase A
Manual SQL/filter matching.

### Phase B
Rule-based matching.

### Phase C
Behavior-adjusted matching.

Do not build ML matching before enough interactions exist.

---

# Pod Activities

Start with only a few structured formats:

## Speaking Pair Rotation
Short scheduled practice.

## Writing Exchange
Structured rubric-based peer feedback.

## Accountability Check-in
Planned session → completion.

## Weekend Mock Room
Optional cohort activity.

---

# Peer Feedback Guardrail

Peer feedback must be labeled:

> Peer feedback

Never:

> IELTS score

ARUORA may provide structured prompts based on public scoring criteria, but peers are not official examiners.

---

# Matching Success Metrics

- invitation acceptance
- first peer session
- repeat peer session
- pod activity/week
- no-show rate
- peer usefulness rating
- retention difference: pod vs non-pod
- learning outcome difference

---

# Kill Criteria

If manual Pods show:
- low acceptance
- near-zero repeat interaction
- high moderation burden
- no retention benefit

Do not automate the feature.

Revisit the social-learning hypothesis.
