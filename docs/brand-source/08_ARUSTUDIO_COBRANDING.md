# 08 — ARUSTUDIO Co-Branding & Character Universe

## 1. Brand Architecture

```text
ARUSTUDIO
│
├── Aru
│   └── Studio Mascot
│
└── ARUORA
    │
    ├── Aura
    │   └── Product Companion
    │
    ├── IELTS
    └── Future Tracks
```

---

# 2. Aru

Aru represents:

- ARUSTUDIO
- creator identity
- studio character
- broader creative universe

Aru should not become the daily learning companion inside ARUORA.

---

# 3. Aura

Aura represents:

- ARUORA
- learning intelligence
- language journey
- student companion
- AI interface

---

# 4. Shared DNA

Aru and Aura may share:

- 3D collectible visual style
- minimal facial language
- horn motif
- calm quirky personality
- soft materials
- warm studio rendering

---

# 5. Different Identity

## Aru
- deeper red / dark palette
- physical horns
- studio identity
- broader creative personality

## Aura
- cream / black / violet
- light horns
- nerd scholar identity
- learning companion

---

# 6. Co-Appearance

When Aru and Aura appear together:

- Aru should not visually dominate ARUORA campaign
- Aura is product owner within ARUORA context
- Aru can act as creator/founder/studio cameo

---

# 7. Dialogue Dynamic

Possible:

**Aru:** quiet, wholesome, slightly weird.

**Aura:** observant, intelligent, dry.

Example:

Aru:
> “I think that was correct.”

Aura:
> “It wasn't.”

This may be used for social media, not serious learning feedback.

---

# 8. Parent Brand Endorsement

Preferred:

> **ARUORA — by ARUSTUDIO**

Use on:

- website footer
- about page
- launch announcement
- app store listing
- pitch deck

Do not repeat on every screen.

---

# 9. Future Character Rule

If ARUSTUDIO creates more product mascots:

- they may share one visual trait from Aru
- they must have product-specific identity
- do not create random characters merely for decoration

ARUSTUDIO should build a coherent character universe, not a mascot collection.
