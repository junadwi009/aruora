# 10 — ARUORA Brand Governance Checklist

Use this file as QA before merging major visual/product changes.

---

# A. Brand

- [ ] Product name uses **ARUORA**
- [ ] Parent endorsement uses **by ARUSTUDIO** only where relevant
- [ ] Tagline is **Your journey starts with language.**
- [ ] ARUORA is not described as an official IELTS examiner
- [ ] Product messaging stays outcome/destination-oriented

---

# B. Color

- [ ] Main light surface is neutral/cream, not purple-heavy
- [ ] Aura Violet is accent, not universal background
- [ ] Aurora gradient is reserved for meaningful states
- [ ] Success is not indicated by color alone
- [ ] Contrast has been checked before production

---

# C. Typography

- [ ] UI uses the approved primary sans family
- [ ] Headings are clear and not overly decorative
- [ ] Body copy remains readable
- [ ] Font weights are not excessively thin

---

# D. Shape

- [ ] Cards use soft geometry
- [ ] Not every control is a pill
- [ ] Radius is consistent
- [ ] Shadows are restrained

---

# E. Logo

- [ ] No generic graduation-cap/book/globe symbol
- [ ] Logo works monochrome
- [ ] Logo remains readable at small size
- [ ] Mascot is not required for logo recognition

---

# F. Aura

- [ ] Black bob haircut retained
- [ ] Straight bangs retained
- [ ] Round glasses retained
- [ ] Calm/observant expression retained
- [ ] Light horns retained
- [ ] Cream/minimal outfit retained
- [ ] Aura remains nerdy but not childish
- [ ] Aura adds functional context when shown

---

# G. Aura Voice

- [ ] Concise
- [ ] Calm
- [ ] Specific
- [ ] No guilt
- [ ] No excessive praise
- [ ] No fake certainty
- [ ] No exam-score guarantees
- [ ] Humor is subtle and safe

---

# H. UI Hierarchy

- [ ] Destination is visible where relevant
- [ ] Readiness is more important than streak
- [ ] Weakest skill is easy to understand
- [ ] User has one obvious next action
- [ ] Flow/gamification remains secondary

---

# I. Community

- [ ] Community UI is goal/skill focused
- [ ] No follower-count-first social design
- [ ] Peer interaction requires opt-in
- [ ] Similar-level matching is contextual
- [ ] Safety/report controls planned before public matching

---

# J. Motion

- [ ] Motion is calm
- [ ] No excessive bounce
- [ ] Achievement animation is reserved
- [ ] Reduced-motion mode is supported

---

# K. Sonic

- [ ] No harsh buzzer
- [ ] Sounds are optional
- [ ] Correct/wrong cues are subtle
- [ ] Audio learning functionality is independent from UI sounds

---

# L. Product Consistency

Before merging any major feature, answer:

1. Does this make ARUORA feel more like ARUORA?
2. Does it improve clarity, progress, or belonging?
3. Is this functional, or merely decorative?
4. Does it preserve a mature scholarship/career audience?
5. Would this still make sense if JLPT is added later?

If #2 and #3 are both “no”, reconsider the feature.
