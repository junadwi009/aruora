# 09 — Product Brand Implementation

## 1. Objective

Translate ARUORA identity into the existing IELTS Coach product without breaking working functionality.

---

# 2. Rebranding Priorities

## Priority 1 — Identity

Replace:

- IELTS Coach naming
- generic book icon brand mark
- legacy color system

With:

- ARUORA
- ARUORA mark / placeholder mark
- brand tokens

---

## Priority 2 — Information Hierarchy

Shift home focus from:

- skill cards
- streak
- generic practice

Toward:

- destination
- target band
- readiness
- biggest gap
- deadline
- recommended session

---

## Priority 3 — Aura

Add Aura progressively.

Minimum viable placements:

1. onboarding completion
2. placement result
3. home recommendation
4. meaningful improvement
5. feedback / help
6. future WhatsApp identity

---

# 3. Onboarding Brand Flow

Recommended future onboarding:

```text
Welcome to ARUORA
↓
What are you working toward?
↓
Scholarship / Study / Work
↓
Where are you heading?
↓
Target IELTS
↓
Deadline / exam month
↓
Placement
```

Do not overload with full profiling at first contact.

---

---

# 5. Placement Result

Use ARUORA visual language:

- cream background
- ink typography
- violet active state
- mint for improvement
- Aura nearby
- subtle orbit/path

Do not use dramatic gradient background.

---

# 6. Progress

Replace generic charts where possible with:

- score trajectory
- gap-to-target
- readiness
- meaningful sessions
- skill trend

Gamification metrics remain secondary.

---

# 7. Study Flow

Daily training CTA must answer:

> “What should I do now?”

Not:

> “Which module do you want to browse?”

---

# 8. Aura Integration Rules

Aura should:

- summarize
- recommend
- react
- explain

Aura should not:

- interrupt every task
- restate obvious UI copy
- create long chat bubbles during timed practice

---

# 9. Community Preparation

Even before community UI exists, collect opt-in data such as:

- open to peer practice
- preferred skill
- availability
- target band
- exam timeline

This supports future Study Pool.

---

# 10. WhatsApp Preparation

Future Aura WhatsApp is a channel, not the core learning environment.

WhatsApp may handle:

- onboarding lead profiling
- reminder
- re-engagement
- result notification
- matching invitation

Core training remains in ARUORA.

---

# 11. Founding Learner

UAT / beta users may receive:

> **Founding Learner · 2026**

Use as:

- badge
- community status
- future alumni identifier

Do not over-gamify it.

---

# 12. Core UX Acceptance Question

For every major screen ask:

> Does this screen help the learner understand where they are, what matters, or what to do next?

If not, simplify.
