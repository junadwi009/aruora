# 07 — ARUORA Motion & Sonic Identity

## 1. Motion Personality

ARUORA motion:

**slow · smooth · intentional**

Avoid:

- elastic bounce
- excessive spring
- arcade-style pop
- confetti after small actions

---

# 2. Motion Timing

Starter:

| Interaction | Duration |
|---|---:|
| Button state | 150–180ms |
| Small transition | 180–220ms |
| Card transition | 200–250ms |
| Panel/modal | 220–320ms |
| Aura reaction | 400–900ms |
| Achievement | 900–1600ms |

---

# 3. Aura Motion

## Idle
Very subtle:

- blink
- breathing
- slight glasses adjustment
- horn glow

## Thinking
Possible sequence:

- eyes shift
- small pause
- Spark appears
- answer displays

## Listening
- horn glow pulse
- ribbon waveform
- slight forward attention

## Correct
- tiny upward motion
- subtle mint/violet glow

## Excellent
- broader aurora sweep
- one Spark
- short smile / eye change

## Wrong
- no shake
- no red explosion
- slight eye shift
- concise feedback

---

# 4. Loading

Avoid generic spinner when Aura is present.

Possible ARUORA loading motif:

```text
○ → ◉ → ◎ → ✦
```

or orbit rotation.

Must still provide accessible loading state.

---

# 5. Readiness Progress

Progress animation:

- smooth fill
- no celebratory explosion
- aurora appears only when meaningful threshold is crossed

---

# 6. Achievement Motion

For important milestones:

1. background subtly dims
2. path / orbit brightens
3. Aura reacts
4. score or milestone appears
5. aurora ribbon sweeps
6. return to normal

---

# 7. Reduced Motion

When reduced motion is enabled:

- remove floating
- remove large sweep
- use opacity change
- use static glow
- keep functional state transitions

---

# 8. Sonic Identity

Sound must be:

- soft
- brief
- non-intrusive
- low anxiety

---

# 9. Suggested Sound Language

## Correct
Soft glass note.

## Excellent
Short harmonic shimmer.

## Achievement
Three gentle ascending tones.

## Error / wrong
Muted soft tap.

## Aura activation
Very subtle airy tone.

---

# 10. Avoid

- casino sounds
- loud ding
- buzzer
- alarm
- repetitive streak sound
- childish cartoon effects

---

# 11. Sound Control

Users must be able to:

- mute all UI sounds
- keep speaking/listening audio functional
- control notification sound through system settings

Sound is enhancement, never required for understanding.
