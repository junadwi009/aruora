**Parent Studio Mascot:** Aru  
**Version:** 1.0  
**Status:** Development baseline

---

## Purpose

Dokumentasi ini menjadi sumber acuan brand identity ARUORA untuk:

- UI/UX product development
- website dan landing page
- social media
- UAT / Founding Learner communication
- character design Aura
- motion dan sound
- future IELTS/JLPT expansion
- AI-assisted development dengan Codex, Claude, atau agent lain

ARUORA tidak diposisikan sebagai aplikasi belajar bahasa generik.

> **ARUORA is a goal-driven language preparation platform for people going somewhere.**

Fokus awal adalah IELTS untuk:

- scholarship hunters
- mahasiswa yang ingin kuliah di luar negeri
- young professionals
- overseas career preparation
- IELTS retakers

Community, peer matching, mentor, dan tutor dapat berkembang kemudian, tetapi brand identity dari awal harus cukup fleksibel untuk mendukung ekosistem tersebut.

## Non-negotiables

1. ARUORA **bukan Duolingo clone**.
2. Aura boleh lovable, tetapi **tidak childish**.
3. Gradient aurora adalah **signal**, bukan dekorasi universal.
4. UI harus memprioritaskan **destination, readiness, dan learning action** dibanding gamification.
5. Aura adalah companion dan AI identity, bukan sekadar sticker.
6. Aru adalah maskot ARUSTUDIO; Aura adalah maskot ARUORA.
7. ARUORA light UI menggunakan **cream + ink + violet accent**, bukan purple-heavy UI.
8. Jangan menggunakan graduation cap, globe, open-book logo, atau icon EdTech generik sebagai primary brand mark.

## Current Visual Direction

ARUORA memiliki visual universe berbasis:

- warm cream surfaces
- black / midnight typography
- restrained violet accents
- subtle aurora glow
- soft collectible-figure character rendering
- rounded but mature interface geometry
- clean line icons
- quiet, intelligent motion

Aura adalah perempuan chibi nerd dengan:

- black bob haircut
- straight bangs
- large round glasses
- calm / slightly unimpressed expression
- cream oversized outfit
- small luminous horns
- restrained lavender aurora accents
