# 03 — ARUORA Logo & App Icon Direction

## 1. Wordmark Direction

Preferred presentation:

# `aruora`

Lowercase is preferred because it feels:

- human
- modern
- calm
- less institutional
- compatible with Aura's soft visual language

Uppercase `ARUORA` may still be used in documentation, headings, and co-branding.

---

# 2. Logo Philosophy

Logo must avoid common EdTech cliché:

- graduation cap
- globe
- open book
- speech bubble
- pencil
- university crest

ARUORA is not a tutoring institution logo.

---

# 3. Signature Letter Opportunity

The **O** in `aruora` can become the primary experimental area.

Possible interpretations:

- Aura Core
- orbit
- journey node
- spark inside circle
- subtle glowing center

Do not make the O overly decorative.

Wordmark must remain readable at small size.

---

# 4. Secondary Mark

Recommended concept:

> **Orbit + Spark**

Example abstraction:

```text
   ✦
  ◯
```

or a more custom `A + orbit`.

The final icon should be custom-designed, not literal unicode symbols.

---

# 5. App Icon

Primary recommendation:

**Do not use Aura's face as the default app icon.**

Reason:

- maintain premium/productivity feel
- avoid appearing as children's game
- allow Aura to remain a character inside the experience
- make brand mark scalable across future tracks

App icon direction:

- warm cream or midnight base
- simple ARUORA symbol
- restrained violet
- optional tiny spark
- no text at mobile icon size

---

# 6. Aura in Logo

Aura should not be permanently embedded in the core wordmark.

Allowed:

- campaign logo lockup
- social mascot composition
- seasonal branding
- UAT / Founding Learner campaign

Core logo must work without mascot.

---

# 7. Parent Brand Lockup

Preferred:

```text
aruora
by ARUSTUDIO
```

`by ARUSTUDIO` must remain secondary.

Do not create equal hierarchy:

```text
ARUSTUDIO x ARUORA
```

for normal product UI.

Use co-branding only where parent identity is relevant.

---

# 8. Minimum Usage Rules

Until final logo is designed:

- do not stretch wordmark
- do not rotate
- do not add glow permanently
- do not put multiple gradients inside letters
- do not combine with random education icons
- keep at least 0.5× logo height as clear space

---

# 9. Monochrome Requirement

Final logo must work in:

- black
- white
- single-color violet
- grayscale print

If logo only works with gradient, it is not robust enough.

---
